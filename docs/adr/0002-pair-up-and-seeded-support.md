# Explicit pairing and a persisted battle seed

Adjacent scalar support did not model Awakening's shared-square Pair Up decisions. Store the reserve's explicit front-unit reference and a seeded support-roll state in a version 2 schema, migrating existing v1 armies/checkpoints to unpaired units. Only valid reciprocal spatial occupancy is permitted; ordinary overlap remains invalid. Switch/separate transfer or consume the pair's existing activity rather than granting extra turns. Retry restores its checkpoint seed as well as army/bonds.
